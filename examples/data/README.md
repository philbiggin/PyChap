# Example data: 4PIR

`4pirtm.pdb`, `4pirtm.xtc`, `4pirtm.tpr` are upstream CHAP's own default
worked example, described at
https://www.channotation.org/docs/annotation_example/: the transmembrane
domain of a serotonin-gated ion channel (PDB entry
[4PIR](https://www.rcsb.org/structure/4PIR), a homopentameric Cys-loop
receptor), embedded in a POPC lipid bilayer and solvated in NaCl
solution, prepared and simulated with GROMACS.

| File | Size | Contents |
|---|---|---|
| `4pirtm.pdb` | ~14 MB | Single structure snapshot: 175,315 atoms (protein + POPC + water + ions) |
| `4pirtm.tpr` | ~9 MB | GROMACS run-topology file (GROMACS 5.1 format), pairs with the `.xtc` |
| `4pirtm.xtc` | ~7 MB | Trajectory: same 175,315 atoms, 10 frames covering 10 ns |

Of the 175,315 atoms, 12,113 are protein (the rest are lipid, water, and
ions) -- see `examples/run_4pir_example.py`, which selects just those
for the pathway analysis.

These files are used directly by:

- `examples/run_4pir_example.py` (defaults to `data/4pirtm.pdb`) --
  works out of the box, no MDAnalysis needed. Writes into
  `examples/4pir_output/`, files prefixed `p4pir_`.
- `examples/run_4pir_trajectory_example.py` (defaults to
  `data/4pirtm.tpr` + `data/4pirtm.xtc`) -- needs `pip install MDAnalysis`.
  Also writes into `examples/4pir_output/` (same directory as above),
  files prefixed `p4pir_traj_` so nothing collides.

Note the generated output files are prefixed `p4pir_`/`p4pir_traj_`
(not `4pir_`): PyMOL's `load` (and other tools) derive a default object
name from a file's basename when you don't specify one explicitly, and
PyMOL object/selection names can't *start* with a digit -- so a
filename like `4pir_annotated.pdb` would silently misbehave if loaded
that way. `4pirtm.pdb`/`.tpr`/`.xtc` themselves keep their original
upstream names (they're input data, not generated by this package), so
avoid loading them into PyMOL without giving them an explicit object
name too, e.g. `load data/4pirtm.pdb, structure`.
